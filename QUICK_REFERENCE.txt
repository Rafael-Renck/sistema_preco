================================================================================
SISTEMA DE PREÇOS - QUICK REFERENCE
================================================================================

VISÃO GERAL
  Aplicação Flask para gerenciar, consultar e comparar tabelas de preços
  de procedimentos médicos (CBHPM, DTP) com suporte multi-operadora.

TECNOLOGIA
  Backend:      Flask 3.0.3 + SQLAlchemy ORM
  Database:     MySQL  
  Frontend:     HTML5, CSS3, JavaScript ES6+
  Export:       PDF (ReportLab), Excel (openpyxl, xlsxwriter)

TAMANHO DO PROJETO
  Linhas:       11.323 (app.py)
  Funções:      254 (routes + helpers)
  Templates:    35+ (HTML)
  CSS:          30+ arquivos
  JavaScript:   5+ módulos
  Modelos:      29 tabelas

ROTAS PRINCIPAIS POR CATEGORIA
================================================================================

AUTENTICAÇÃO (8 rotas)
  POST   /login                      - Login
  GET    /logout                     - Logout
  POST   /minha-senha                - Trocar senha
  GET    /health                     - Health check

ADMIN - USUÁRIOS (4 rotas)
  GET    /gerenciar-usuarios         - Listar
  POST   /usuarios/novo              - Criar
  POST   /usuarios/<id>/editar       - Editar
  GET    /admin/audit-trail          - Auditoria

ADMIN - OPERADORAS (3 rotas)
  GET    /gerenciar-operadoras       - Listar
  POST   /operadoras/nova            - Criar
  POST   /operadoras/<id>/editar     - Editar

ADMIN - TABELAS (10 rotas)
  GET    /gerenciar-tabelas          - Listar
  POST   /tabelas/importar/cbhpm     - Importar CBHPM
  POST   /tabelas/importar/diarias-taxas-pacotes - Importar DTP
  POST   /tabelas/uco/definir        - Definir UCO

ADMIN - CBHPM TETOS (7 rotas)
  GET    /admin/tetos                - Gerenciar tetos
  POST   /admin/tetos/import         - Importar
  POST   /admin/tetos/copy           - Copiar entre operadoras
  GET    /cbhpm/regras               - Regras customizáveis

CONSULTA & COMPARAÇÃO (8 rotas + APIs)
  GET    /                           - Home
  GET    /consulta-comparar          - Interface
  GET    /consulta-comparar-novo     - Nova interface (design moderno)
  POST   /api/simulacao_cbhpm        - Simulação
  POST   /api/simulacao_cbhpm/pdf    - Exportar PDF
  POST   /api/simulacao_cbhpm/xlsx   - Exportar Excel

SMART FILTERS - NOVO (3 APIs)
  GET    /api/tabela-info/<id>       - Detecta tipo (CBHPM vs DTP)
  GET    /api/prestadores/<id>       - Lista prestadores
  GET    /api/versoes/<id>           - Lista versões CBHPM

TUSS/ROL (4 rotas)
  GET    /tuss-rol                   - Busca
  GET    /admin/tuss-rol             - Admin
  GET    /api/tuss-rol               - API

INSUMOS (8 rotas)

  GET    /insumos/search             - Buscar
  POST   /insumos/import             - Importar
  GET    /insumos/import/jobs        - Status de jobs

CONTRATOS (2 rotas)

================================================================================
PROBLEMA: App.py com 11k linhas
================================================================================

IMPACTO: Dificuldade de manutenção

SOLUÇÃO: Refatorar em Blueprints
  blueprints/
    ├── auth.py (login, logout, senhas)
    ├── admin.py (usuários, operadoras, auditoria)
    ├── tabelas.py (CRUD de tabelas)
    ├── consulta.py (comparação, simulação)
    ├── insumos.py (catálogo, importação)
    ├── cbhpm.py (tetos, regras)
    └── api.py (endpoints JSON)
  
  models/
    ├── usuario.py
    ├── operadora.py
    ├── tabela.py
    ├── procedimento.py
    └── ...

  Benefícios:
    - Mais fácil de ler e entender
    - Testes unitários por módulo
    - Coexistência de versões antigas/novas
    - Lazy loading de blueprints
